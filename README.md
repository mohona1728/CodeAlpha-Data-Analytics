CodeAlpha Data Analytics Internship

Project: Exploratory Data Analysis and Data Visualization

Project Overview

This project focuses on analyzing healthcare waiting-time and patient-satisfaction data using Python. The goal is to explore the dataset, calculate descriptive statistics, compare departments, and present key findings through charts.

Objectives

- Calculate average, minimum, and maximum waiting times.
- Compare average waiting times across departments.
- Analyze patient satisfaction scores.
- Visualize the findings using charts.

Tools and Technologies

- Python
- Google Colab
- Pandas
- Matplotlib
- Seaborn

Key Findings

- Overall average waiting time: 26.5 minutes.
- Longest waiting time: 45 minutes.
- Shortest waiting time: 10 minutes.
- Mean patient satisfaction: 3.8 out of 5.
- Surgery had the highest average waiting time among the departments analyzed.

Project Files

- "CodeAlpha_EDA_Visualization.ipynb" — Notebook containing the analysis and visualizations.
- Dataset — To be included in the repository if required.

Data Note

These findings are based on the dataset analyzed in this project. If synthetic data was used, the results are for educational purposes only and should not be interpreted as findings from a real healthcare facility.
