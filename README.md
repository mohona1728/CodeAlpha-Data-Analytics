📁 Completed Projects

🔹 Task 1: Web Scraping

Objective: To collect and organize book information from a website using Python.

Tools: Python, Requests, BeautifulSoup, Pandas.

Activities:

- Retrieved webpage content using the Requests library.
- Extracted book titles, prices, availability, and ratings using BeautifulSoup.
- Organized the collected information into a structured DataFrame.
- Performed basic data quality checks.
- Exported the scraped data into a CSV file.

Project Files:

- 📓 Notebook: https://github.com/mohona1728/CodeAlpha-Data-Analytics/blob/main/CodeAlpha_Task_1_web_Scraping.ipynb
- 📄 Dataset: https://github.com/mohona1728/CodeAlpha-Data-Analytics/blob/main/CodeAlpha_Task1_Scraped_Books.csv

🔹 Task 2: Exploratory Data Analysis (EDA)

Objective: To explore and understand a sample healthcare waiting-time dataset.

Tools: Python, Pandas.

Activities:

- Loaded and explored the healthcare dataset.
- Examined dataset structure and statistical information.
- Checked missing values and duplicate records.
- Performed data quality checks.
- Identified patterns and important insights.

Project Files:

- 📓 Notebook: https://github.com/mohona1728/CodeAlpha-Data-Analytics/blob/main/CodeAlpha_EDA_visualization.ipynb
- 📄 Dataset: https://github.com/mohona1728/CodeAlpha-Data-Analytics/blob/main/healthcare_waiting_time.csv 

🔹 Task 3: Data Visualization

Objective: To present healthcare dataset findings through meaningful visualizations.

Tools: Python, Pandas, Matplotlib.

Activities:

- Created charts to explore healthcare waiting-time patterns.
- Visualized comparisons across healthcare departments.
- Presented important findings in graphical formats.
- Used visual analysis to communicate data patterns and comparisons.

Project Files:

🔹 Task 4: Sentiment Analysis

Objective: To analyze customer reviews and classify their sentiments.

Tools: Python, Pandas, VADER Sentiment Analysis, Matplotlib.

Activities:

- Created a sample dataset containing 15 customer reviews.
- Applied VADER sentiment analysis.
- Classified reviews into Positive, Negative, and Neutral categories.
- Calculated sentiment counts and percentages.
- Created bar and pie charts to visualize sentiment distribution.
- Exported the analyzed dataset into a CSV file.

Project Files:

- 📓 Notebook: https://github.com/mohona1728/CodeAlpha-Data-Analytics/blob/main/CodeAlpha_Task_4_Sentiment_Analysis.ipynb
